## Decisions for this module

- **SSR/SSG.** Pages are prerendered at build time (`/`, `/settings`) and hydrated. Static content (toolbar, links, headings, form labels) is always in the HTML. Interactive pieces that depend on the producer (table, Pause/Resume, status) render a skeleton until the producer has started in the browser.
- **Worker start.** Not an app initializer, because that would block bootstrap. The root `App` calls `producer.start()` in `afterNextRender` (browser only, after hydration). `start()` is async and dynamically imports the worker module (`await import('./producer.worker?worker')`), so the worker and Wasm code are a separate chunk that is never loaded on the server.
- **No raw `import.meta`:** Vite's `?worker` import bundles the worker as a hashed chunk and builds its URL from `base` itself. Build-time values come from `src/environments/environment.ts` (01) only.
- **RxJS wrapper.** `rxWorker()` turns a `Worker` into a typed `Observable` stream plus `send`/`terminate`. The service consumes it with `filter` (stale `runId`) and `takeUntilDestroyed`.
- **Signal forms** (`@angular/forms/signals`: `form`, `FormField` directive `[formField]`, `required`/`min`/`max`/`validate`, `submit`).
- **Formatting** uses Angular pipes: `currency` and `number`. `CentsPipe` (cents → dollars) chains into `currency`. `bigint` isn't supported by `DecimalPipe`, so the plan adds a `BigIntPipe` and a `formatBigInt()` utility.
- **Tests** use Angular Testing Library (`render`, `screen`, `userEvent`) and Vitest fixtures (`test.extend`) instead of hand-rolled render helpers. Queries go by role and label, not `data-testid`.
- **Styles.** SCSS everywhere: global `styles.scss` with a Material theme, plus component `.scss` files.

## Interfaces produced

`producer/worker-channel.ts`:

```ts
export interface RxWorker<In, Out> {
  /** Hot, shared stream of worker messages. Errors on worker `error`/`messageerror`; completes on terminate. */
  readonly messages$: Observable<Out>;
  send(message: In): void;
  /** Terminates the worker and completes `messages$`. Idempotent. */
  terminate(): void;
}
export function rxWorker<In, Out>(worker: Worker): RxWorker<In, Out>;
```

```ts
  readonly status: Signal<ProducerStatus>;     // starts 'initializing'
  readonly error: Signal<string | null>;       // starts null
  readonly rows: Signal<MetricsRow[]>;         // starts [] (symbols unknown until loaded)
  readonly settings: Signal<ProducerSettings>; // starts DEFAULT_SETTINGS
  /** true once the first status from the current run arrived (drives skeletons). */

  start(): Promise<void>;                      // idempotent (same promise); resolves immediately on the server
  apply(settings: ProducerSettings): void;
  pause(): void;
  resume(): void;

```

Behaviour:
- `start()`: browser only. Loads the symbol list and the worker in parallel (`Promise.all`). A symbol-list failure sets status `error` with `Failed to load instrument list: <message>`. Then it wraps the worker with `rxWorker`, subscribes to `messages$`, filtering on `runId === current` (`takeUntilDestroyed`), then sends `{ type: 'apply', runId, config: toProducerConfig(settings(), symbols) }` and sets rows to that config's `emptyRow`s. A loader failure sets status `error` with `Failed to start producer: <message>`.
- `apply(s)`: `runId++`; `settings.set(s)`; if the symbols are loaded: `config = toProducerConfig(s, symbols)`, `rows.set(config.symbols.map(emptyRow))`; `status.set('initializing')`; `error.set(null)`; then send `{ type: 'apply', runId, config }` if the channel is ready. If it isn't ready yet, `start()` sends the latest settings once it is.
- `pause()`/`resume()` send with the current `runId`.
- On a `status` message: set status, set `error ?? null`, set `started` to true. On a `snapshot`: `rows.set(data.rows)`.
- If `messages$` errors (worker crash): status `error`, error `err.message || 'Producer worker failed'`.
- `DestroyRef.onDestroy` → `channel.terminate()`.

```ts
/** Fake Worker recording sent messages; `emit`/`crash` drive the main-thread side. */
export class FakeWorker {
  sent: unknown[] = [];
  terminated = false;
  private listeners = new Map<string, Set<(e: Event) => void>>();
  addEventListener(type: string, fn: (e: Event) => void) { (this.listeners.get(type) ?? this.listeners.set(type, new Set()).get(type)!).add(fn); }
  removeEventListener(type: string, fn: (e: Event) => void) { this.listeners.get(type)?.delete(fn); }
  postMessage(m: unknown) { this.sent.push(m); }
  terminate() { this.terminated = true; }
  emit(data: unknown) { this.listeners.get('message')?.forEach((fn) => fn(new MessageEvent('message', { data }))); }
  crash(message: string) { this.listeners.get('error')?.forEach((fn) => fn(new ErrorEvent('error', { message }))); }
```
