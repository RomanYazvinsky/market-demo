# Analysis
## dashboard page
- UI is a table and buttons for start/stop + status
- Table has N rows of products (to generate, let's say stocks of a company)
- Table has 6 columns:
  1. name of a product
  2. Last traded price
  3. Bid-ask spread
  4. Trading volume
  5. VWAP
  6. Order-book imbalance
- Table receives updates per period
- Format cells (currency, number)
## Table updates (trades)
- generated by wasm script (defined later)

## settings page
- configures producer settings
- settings do not persist after reload
- apply button clears all data and starts new generation
